# NordicTechTour2026
Slides for NTT2026

## Directory structure

Each country has one folder per city, and each city folder holds that event's slides and agenda. The date of each event is taken from its agenda file.

```
NordicTechTour2026/
└── France/
    ├── Lyon/    (18 November 2026)
    └── Paris/   (19 November 2026)
```

| Folder | Event date | Contents |
|---|---|---|
| `France/Lyon` | 18 November 2026 | Agenda, intro and solutions, AI assisted development and edge AI, short range (French), Wi-Fi, cellular connectivity, PMIC, nRF Cloud |
| `France/Paris` | 19 November 2026 | Agenda, intro and solutions, AI assisted development and edge AI, short range (French), Wi-Fi, cellular connectivity, PMIC, nRF Cloud and CRA |
